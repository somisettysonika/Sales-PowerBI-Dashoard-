# 📊 Sales Power BI Dashboard

## 📌 Project Overview

This project focuses on developing an interactive Sales Analytics Dashboard using Microsoft Power BI to analyze business performance and transform raw data into meaningful insights.

The dashboard provides a visual representation of sales-related metrics, helping users understand business trends, monitor performance and support data-driven decision-making.

## 🎯 Project Objectives

- Analyze sales performance using interactive visualizations.
- Monitor important business KPIs.
- Identify sales trends and patterns.
- Present business information through an interactive dashboard.
- Support data-driven business decisions.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and data visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX (Data Analysis Expressions)** – Measures and calculations.
- **Data Modeling** – Establishing relationships between data tables.

## 📈 Dashboard Features

- Interactive KPI cards.
- Sales performance analysis.
- Data visualization through charts and graphs.
- Dynamic filters and slicers.
- Business performance monitoring.
- Interactive report navigation.
